    Cómo leer este portafolio

    Cada entrada separa con claridad cuatro tipos de afirmación, para que se pueda verificar de dónde sale cada cosa:

    • Hecho documentado respaldado por una fuente citada.
    • Resultado calculado sale de una ecuación y parámetros declarados.
    • Supuesto del modelo simplificación adoptada para poder calcular.
    • Hipótesis o ilustrativo plausible, pero no demostrado aquí.

    Los datos de las gráficas son generados a partir de modelos declarados, no mediciones, salvo que se diga lo contrario. Donde no se encontraron datos públicos fiables (neumáticos de Fórmula 1), la curva está marcada como hipotética y no se atribuye a ningún fabricante ni experimento.

    Las citas aparecen como (Autor, año) y enlazan a la lista de referencias.
