Método

Cómo leer este portafolio

Cada entrada separa con claridad cuatro tipos de afirmación, para que se pueda verificar de dónde sale cada cosa:

  • Hecho documentado respaldado por una fuente citada.
  • Resultado calculado sale de una ecuación y parámetros declarados.
  • Supuesto del modelo simplificación adoptada para poder calcular.
  • Hipótesis o ilustrativo plausible, pero no demostrado aquí.

Las gráficas indican siempre de dónde salen sus datos. Los temas 6 y 9 usan datos reales (el ciclo de manejo UDDS de la EPA y las efemérides de las Voyager de NASA/JPL); los demás usan datos generados a partir de modelos declarados. Donde no se encontraron datos públicos fiables (neumáticos de Fórmula 1), la curva está marcada como hipotética.

Las citas aparecen como (Autor, año) y enlazan a la lista de referencias. Toda gráfica se puede descargar en CSV.
